# Veritas Documentation

<Callout type="info" emoji="🎯">
  **Decentralized Reputation Protocol for Prediction Markets**

  Veritas aggregates prediction market performance across multiple platforms into a unified, soulbound NFT-based identity.
</Callout>

## What is Veritas?

Veritas solves **reputation fragmentation** in prediction markets. Traders build track records across multiple platforms (DreamDEX, Polymarket, Azuro, etc.), but this history is siloed and non-portable.

### The Solution

## Quick Start

<Steps>

### Connect Your Wallet

Visit [Veritas](https://veritas.xyz) and connect your Web3 wallet (MetaMask, WalletConnect, etc.)

### Register & Mint NFT

Pay a small fee (0.0005 STT) to mint your soulbound Reputation NFT

### Import Predictions

Connect platforms and import your prediction history to build your VeritasScore

### Climb the Leaderboard

Compete globally and enable copy trading when you reach Gold tier

</Steps>

## Tech Stack

<Tabs items={['Frontend', 'Smart Contracts', 'Backend']}>
  <Tabs.Tab>
    - **Framework:** Next.js 14 (App Router)
    - **Language:** TypeScript
    - **Styling:** Tailwind CSS
    - **Web3:** wagmi v2, viem, RainbowKit
    - **UI:** Radix UI, shadcn/ui
    - **Animations:** GSAP, Framer Motion

    - **Framework:** Foundry
    - **Libraries:** OpenZeppelin
    - **Network:** STT Smart Chain

  </Tabs.Tab>
  <Tabs.Tab>
    - **Database:** Supabase (PostgreSQL)
    - **Indexing:** Custom viem indexers
    - **Runtime:** Node.js v22+
